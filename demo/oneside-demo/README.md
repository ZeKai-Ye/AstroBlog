# 工作与时日 — 纸本个人博客 Demo

方向 A「纸本」已按选择深化为个人博客 **「工作与时日 / WORK & DAYS」**。以工作与时日为主题，保留纸感、宋体与大量留白，并加入实时日晷、夜读模式与完整的阅读动效。

**在线预览：** 启动本地静态服务后打开 `index.html`；也可以直接双击该文件浏览，无需构建工具。

## 站点结构

- **首屏**：个人博客标题、手写便签、实时杭州日晷，以及 Vol. 07 版本信息。
- **点线目录**：文章 / 工作 / 时日 / 关于，罗马数字与点线引导，像一本书的目录。
- **最近一篇**：以「慢，是一种工作方法」为封面的编辑式推荐区。
- **文章**：四篇文章索引。桌面端悬停切换右侧摘要卡，点击进入阅读层。
- **工作**：三则以阅读、时间与通讯为主题的工作档案。
- **时日**：短句式时间线，记录很小的日子；旁边是「此刻 / Now」。
- **关于**：作者介绍、基本资料与站点 Colophon。
- **每月一封信**：无后端的订阅表单，提交后显示动效反馈。
- **阅读层**：全屏纸面阅读模式，含阅读进度、文章排版、Esc / 遮罩关闭。
- **工作 / 时日模式**：右上角双向开关，工作（亮灯纸白）与时日（关灯深色）之间切换；日月图标、圆形扫过转场，偏好保存在浏览器中。
- **低对比亮灯阅读**：亮灯模式使用暖纸色与柔和墨色，不用纯黑纯白，降低夜间阅读的眩光。
- **实时日晷**：圆环完整收在首屏内，弧线与光点随杭州时间推进；手机端保留一枚小日晷。
- **方案总览**：`index.html` 中保留 B / C 两个空间设计工作室备选方向。

## 动效与细节

- 首屏标题按行从纸面下沿升起，元信息、侧栏与点线目录随后依次淡入。
- 实时杭州时间、日期与「一天已过 xx%」；首屏圆环上的弧线和光点会随一天推进。
- 顶部 2px 阅读进度线，随页面滚动增长；吸顶导航滚动后轻微收紧。
- 内容进入视口时缓慢上浮；带 2.4 秒自动兜底，不会留下空白。
- 文章索引悬停 / 聚焦时，右侧摘要卡交叉淡入。
- 「时日」的竖向时间线进入视口后由上至下生长。
- 阅读层打开时纸面上浮、标题与正文依次入场；关闭时回落。
- 订阅成功后出现圆形对勾与状态文案。
- 工作 / 时日切换时，从开关位置展开一枚昼夜圆幕；日月图标交叉淡出、淡入，新主题在圆幕覆盖下完成切换。
- 亮灯模式使用低对比暖纸与灰墨，避免夜间阅读时的刺眼反差；所有动效遵循 `prefers-reduced-motion`。

## 参考与转译

这一轮个人化改造参考了以下站点的**设计方法**，没有复制其具体视觉或代码：

- [Rauno Freiberg](https://rauno.me/)：超大字号、单一几何色块、极少但精准的互动。
- [Lynn Fisher](https://lynnandtonic.com/)：版本化个人站点、点线目录、mode 切换的玩心。
- [Maggie Appleton](https://maggieappleton.com/)：数字花园、Now 页面与个人知识现场感。
- [XXIIVV](https://wiki.xxiivv.com/)：手工感、个人百科与 Colophon 式的自我说明。
- [CSS-Tricks: Make it Personal](https://css-tricks.com/make-it-personal/) 与 [FFConf: A Love Letter to Personal Websites](https://ffconf.org/talks/2022_type__error_talk/)：主题切换、古怪小细节与“做自己的网站”的立场。

落到本站：把「时间」做成可读的实时界面，而不是装饰性的圆环；用版本号、目录、便签和「工作 / 时日」昼夜切换建立私人出版物的感觉。

## 设计说明

- 字体使用本机 `Noto Serif SC` / `Noto Sans SC` / Georgia / Segoe UI 等系统字体栈，离线也能保持接近的质感。
- 手写便签使用系统楷体作为点缀，与宋体正文形成轻微的私人笔迹感。
- 所有视觉图形均由 CSS 绘制，不依赖外部图片、字体 CDN 或三方库。
- 品牌、文章、项目、地址与联系方式均为虚构，仅用于设计演示。
- 页面使用语义化结构、跳转主内容的 skip link、可见焦点和 `prefers-reduced-motion` 降级。
